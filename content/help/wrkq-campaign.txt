Manage a container's campaign lifecycle.

Campaigns adorn ordinary containers; the container kind and archive state remain
independent. Brief/specification edits are mechanically retained as full-body
container.updated event snapshots. Use kind=decision container comments for the
curated judgment behind a specification change.
Usage:
  wrkq campaign [flags]
Commands:
  activate    Activate a draft campaign
  close       Declare an active campaign completed or cancelled
  convert     Convert a plain container into a draft or active campaign
  edit        Edit campaign brief or specification
  portfolio   Show the complete campaign portfolio aggregate

Flags:
  -h, --help   help for campaign
Global Flags:
      --as string              Alias for --principal-ref; accepts agent:<id> or a full agent ScopeRef
      --db string              Path to database file (overrides WRKQ_DB_PATH)
      --output string          Output mode: table, human, json, ndjson, porcelain, yaml, tsv, raw
      --principal-ref string   Caller principal for write attribution: agent:<id> or full agent ScopeRef
      --project string         Project to operate under (overrides WRKQ_PROJECT_ROOT)
