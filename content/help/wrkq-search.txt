Search task and comment text
Usage:
  wrkq search <query> [PATH...] [flags]
Flags:
      --assignee string       Filter by assignee principal ref or bare agent slug
      --candidate-limit int   Candidate chunks to retrieve before aggregation (default 300)
      --explain               Include ranking diagnostics in JSON output
      --fresh                 Fail if the search index is stale
  -h, --help                  help for search
      --human                 Force human-readable output
      --json                  Output as JSON
      --kind string           Filter by task kind
      --label stringArray     Filter by exact task label (repeatable; all must match)
      --limit int             Maximum number of task results (default 20)
      --ndjson                Output as newline-delimited JSON
      --porcelain             Stable machine-readable output
      --pretty                Force human-readable output even when not a TTY
      --reverse               Reverse sort order
      --sort string           Sort by relevance, updated_at, or created_at (default "relevance")
      --state string          Filter by state (default open, use all for non-deleted states)
Global Flags:
      --as string              Alias for --principal-ref; accepts agent:<id> or a full agent ScopeRef
      --db string              Path to database file (overrides WRKQ_DB_PATH)
      --output string          Output mode: table, human, json, ndjson, porcelain, yaml, tsv, raw
      --principal-ref string   Caller principal for write attribution: agent:<id> or full agent ScopeRef
      --project string         Project to operate under (overrides WRKQ_PROJECT_ROOT)
