Block until the --until condition is satisfied for watched tasks, then exit.
Shares the exact condition evaluator and exit-code contract with monitor watch --until.

Useful for scripted sequencing: wrkq monitor wait T-00001 --until state=completed
An envelope group waits with: wrkq monitor wait EN-00012 --until terminal
Usage:
  wrkq monitor wait [TASK...] [flags]
Flags:
  -h, --help                 help for wait
      --stall-after string   Exit after this duration with no new events
      --timeout string       Maximum wait duration (e.g. 30m)
      --until string         Condition: state=<s>[,<s>...], all-terminal, acked, or terminal
Global Flags:
      --as string              Alias for --principal-ref; accepts agent:<id> or a full agent ScopeRef
      --db string              Path to database file (overrides WRKQ_DB_PATH)
      --output string          Output mode: table, human, json, ndjson, porcelain, yaml, tsv, raw
      --principal-ref string   Caller principal for write attribution: agent:<id> or full agent ScopeRef
      --project string         Project to operate under (overrides WRKQ_PROJECT_ROOT)
