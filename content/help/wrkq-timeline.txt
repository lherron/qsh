Show the container-neutral composite timeline.

Entries are ordered by durable event id. Outcome display collapses multiple
task.outcome events to the latest text and marks tasks whose outcome was amended.
Usage:
  wrkq timeline <container> [flags]
Flags:
      --cursor string   Continue an event-id-fenced snapshot page
  -h, --help            help for timeline
      --limit int       Maximum entries in this page
Global Flags:
      --as string              Alias for --principal-ref; accepts agent:<id> or a full agent ScopeRef
      --db string              Path to database file (overrides WRKQ_DB_PATH)
      --output string          Output mode: table, human, json, ndjson, porcelain, yaml, tsv, raw
      --principal-ref string   Caller principal for write attribution: agent:<id> or full agent ScopeRef
      --project string         Project to operate under (overrides WRKQ_PROJECT_ROOT)
