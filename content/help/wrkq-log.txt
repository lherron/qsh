Show change history for a task, container, or promise
Usage:
  wrkq log <PATHSPEC|ID> [flags]
Flags:
      --cursor string   Pagination cursor from previous page
  -h, --help            help for log
      --json            Output as JSON
      --limit int       Limit number of events (0 = unlimited) (default 50)
      --oneline         Compact one-line format
      --patch           Show detailed payload changes
      --porcelain       Machine-readable output with cursor on stderr
      --since string    Show changes since date/time (YYYY-MM-DD or RFC3339)
      --until string    Show changes until date/time (YYYY-MM-DD or RFC3339)
Global Flags:
      --as string              Alias for --principal-ref; accepts agent:<id> or a full agent ScopeRef
      --db string              Path to database file (overrides WRKQ_DB_PATH)
      --output string          Output mode: table, human, json, ndjson, porcelain, yaml, tsv, raw
      --principal-ref string   Caller principal for write attribution: agent:<id> or full agent ScopeRef
      --project string         Project to operate under (overrides WRKQ_PROJECT_ROOT)
