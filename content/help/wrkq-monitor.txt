Stream and query task events for agent observation via the Claude Monitor tool.

Subcommands:
  watch [TASK...]   Stream task events (Monitor feed)
  wait  [TASK...]   Block until condition is met, then exit

Examples:
  wrkq monitor watch T-04466 --state-only --until state=completed --timeout 30m
  wrkq monitor wait T-1 T-2 T-3 --until all-terminal --stall-after 30m
  wrkq monitor wait EN-00012 --until terminal --timeout 10m

Exit codes: 0=condition met, or a bounded follow with no --until ended on its
--timeout/--stall-after clock; 1=--until left unmet by timeout/stall;
2=selector error; 3=stream error.
Usage:
  wrkq monitor [flags]
Commands:
  wait        Block until condition is met, then exit
  watch       Stream task events (Monitor feed)

Flags:
  -h, --help   help for monitor
Global Flags:
      --as string              Alias for --principal-ref; accepts agent:<id> or a full agent ScopeRef
      --db string              Path to database file (overrides WRKQ_DB_PATH)
      --output string          Output mode: table, human, json, ndjson, porcelain, yaml, tsv, raw
      --principal-ref string   Caller principal for write attribution: agent:<id> or full agent ScopeRef
      --project string         Project to operate under (overrides WRKQ_PROJECT_ROOT)
